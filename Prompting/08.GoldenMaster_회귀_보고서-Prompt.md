[C] SHealth BMI C++17, Google Test, CMake, ctest
    - 실행 파일: SHealthBMI (shealth.dat 고정 경로, 프로젝트 루트에서 실행)
    - 출력 형식 (SHealthBMI.cpp):
      · [Age-decade BMI distribution] — 20~70대 4분류 비율
      · [Overall BMI distribution] — 전체 4분류 %
      · [Normal BMI users] — count + id 미리보기(최대 10건)
    - 단위 테스트: SHealthBMITest (Google Test)
    - test_plan.md: TC-25 `shealth.dat` 골든 회귀 (P2, 미구현)
    - 데이터: shealth.dat (실데이터, 회귀 기준선용)

[T] SHealthBMI 출력 기반 Golden Master를 설계·구현해줘.

    1) expected 출력 파일 생성/보관 전략
       - 디렉터리: test/golden/ (권장: test/cpp + test/golden 단일 test/ 트리)
       - 파일명: shealth_bmi_report.golden.txt
       - 최초 생성: Green 상태에서 SHealthBMI stdout 캡처 → golden 저장
       - 갱신: UPDATE_GOLDEN=1 또는 cmake --target update-golden (CI 금지)
       - 부동소수: %.2f 출력 고정 + 비교 전 정규화(CRLF·끝 공백)
       - Normal BMI id: count + 상위 10건만 golden 포함

    2) Google Test 파일 비교
       - TEST: GoldenMasterTest.ShealthDatReportMatchesExpected
       - Given: shealth.dat (CMAKE_SOURCE_DIR)
       - When: SHealthBMI subprocess stdout 캡처
       - Then: golden diff 없음 (실패 시 test/golden/actual/ 저장)
       - 헬퍼: readFile, normalizeOutput, runCaptureStdout

    3) CMake/ctest 통합
       - SHEALTH_ENABLE_GOLDEN_TESTS 옵션 (기본 ON)
       - WORKING_DIRECTORY = ${CMAKE_SOURCE_DIR}
       - update-golden 커스텀 타깃

    4) CI (.github/workflows/ci.yml)
       - Ubuntu + Windows 매트릭스, UPDATE_GOLDEN 미설정
       - golden diff 실패 시 actual 아티팩트 업로드

    ## 구현 옵션
    - Option A: subprocess E2E (변경 최소, 권장)
    - Option B: SHealthReporter 추출 (SRP↑, 최소 리팩터링 시)

    ## 제약
    - 기존 단위 TC 회귀 없이 ctest Green
    - shealth.dat 변경 시 golden 갱신 절차 문서화
    - BMI 분류·통계 로직 변경 없이 테스트 인프라만 (Option A)

[F] 산출물:
    - test/cpp/GoldenMasterTest.cpp (또는 SHealthBMITest.cpp 추가)
    - CMakeLists.txt, test/golden/shealth_bmi_report.golden.txt
    - .github/workflows/ci.yml, docs/golden_master.md
    - 실행: cmake --build build && ctest --output-on-failure
    - golden 갱신: cmake --build build --target update-golden
