## 3. 아키텍처 및 처리 파이프라인

### 3.1 SRP 클래스 구조 (154행)

```
SHealthBMI (main)
    └── SHealth (파사드)
            ├── CsvReader        … CSV 로드·파싱
            ├── DataImputer      … weight/height 결측 보정
            ├── BmiCalculator    … BMI 계산·4분류
            ├── BmiStatistics    … 연령대/전체 집계·정상 ID
            └── BmiTypes         … 도메인 타입·상수
```

### 3.2 `processFile` 고정 순서

```mermaid
flowchart LR
    A[CsvReader::load] --> B[DataImputer::imputeMissingValues]
    B --> C[BmiCalculator::applyToAll]
    C --> D[BmiStatistics::compute]
```

| 단계 | 담당 | 책임 |
|------|------|------|
| 1 | `CsvReader` | CSV → `HealthRecord` 벡터 (BMI 미계산) |
| 2 | `DataImputer` | `weightKg==0`, `heightCm==0` → 동 연령대 평균 대체 |
| 3 | `BmiCalculator` | `BMI = weight / (height_m)²`, `record.bmi` 저장 |
| 4 | `BmiStatistics` | 연령대·전체 분포, 정상 BMI 사용자 ID 집계 |

`SHealth::processFile`은 위 4단계 **조율만** 수행하며, God Class 패턴은 제거된 상태입니다.

## 4. 기능별 구현·검증 상세

### 4.1 FI-01 — 특정 연령대 BMI 분포 비율 (155행)

| 항목 | 내용 |
|------|------|
| **입력** | `ageDecade` = 20, 30, 40, 50, 60, 70 |
| **출력** | `CategoryRatios` — 저체중/정상/과체중/비만 4범주 비율(%) |
| **API** | `getDecadeDistribution(ageDecade)`, `getCategoryRatio(ageDecade, category)` |
| **일관성** | `distribution[cat] == getCategoryRatio(decade, cat)` |
| **엣지** | invalid decade → 0%; 해당 대 유효 BMI 0명 → 0% (크래시 없음) |

**구현 위치:** `BmiStatistics::compute` → `getDecadeDistribution` / `getDecadeRatio`  
**테스트:** `DecadeDistributionMatchesCategoryRatio`, `BmiStatisticsTest.EmptyDecade_ReturnsZero`

### 4.2 FI-02 — Height=0 평균치 보정 (156행)

| 항목 | 내용 |
|------|------|
| **트리거** | `heightCm == 0.0` (`PhysicalUnits::kMissingValue`) |
| **규칙** | 동 연령대(10년 단위, 20~70)에서 `height > 0`인 레코드 **평균**으로 대체 |
| **순서** | **weight 보정 → height 보정** → BMI 재계산 |
| **엣지** | 동 대 `validCount == 0` → 미보정 유지 → BMI=0 → 통계 제외 |

**구현 위치:** `DataImputer.cpp` — `imputeFieldByAgeDecade` 공통 함수로 weight/height 재사용  
**테스트:** `ImputeMissingHeightByDecade`, `DataImputerTest.ImputeHeight_ByDecadeAverage`, `DataImputerTest.BothZeroWeightThenHeight_Imputed`

### 4.3 FI-03 — BMI 정상 범위 사용자 ID 목록 (157행)

| 항목 | 내용 |
|------|------|
| **조건** | `18.5 < BMI < 23` **및** `bmi > 0` (무효 BMI 제외) |
| **출력** | `std::vector<int>` — CSV 처리 순서 유지 |
| **API** | `getNormalBmiUserIds()` |
| **엣지** | 0건 → 빈 vector |

**구현 위치:** `BmiStatistics::compute` — `BmiCategory::Normal` 분류 시 `record.id` 수집  
**테스트:** `NormalBmiUserIds`, `BmiStatisticsTest.NormalBmiUserIds_EmptyAndMultiple`

### 4.4 FI-04 — 전체 사용자 BMI 범주별 비율 (158행)

| 항목 | 내용 |
|------|------|
| **대상** | 연령대 무관, `bmi > 0` 전체 레코드 |
| **출력** | 4범주 비율(%) — 합 ≈ **100%** |
| **API** | `getOverallDistribution()`, `getOverallCategoryRatio(category)` |
| **엣지** | 유효 BMI 0명 → 전 범주 0% |

**구현 위치:** `BmiStatistics::compute` — `overallCounts` / `overallTotal`  
**테스트:** `OverallCategoryRatio`, `BmiStatisticsTest.SingleRecord_OverallHundredPercent`

## 10. 도메인 불변식 (검증 확인)

| 규칙 | 구현 | TC |
|------|------|-----|
| BMI = weight(kg) / (height(m))² | `BmiCalculator::compute` | `ComputeBmi` |
| ≤18.5 저체중, 18.5<~23 정상, 23≤~25 과체중, ≥25 비만 | `BmiCalculator::classify` | `ClassifyBmiBoundaries`, TC-13 |
| `heightCm ≤ 0` → bmi=0 | compute 방어 | `Compute_NegativeHeight_ReturnsZero` |
| `bmi ≤ 0` → 통계·ID 목록 **제외** | `BmiStatistics::compute` | `ExcludesNonPositiveBmi` |
| weight=0 → 동 대 평균 체중 | `DataImputer` | `ImputeMissingWeightByDecade` |
| height=0 → 동 대 평균 키 (weight 후) | `DataImputer` | `ImputeMissingHeightByDecade` |
| 연령대 20~70, 10년 단위 | `AgeDecade::*` | `Age20And29`, `Age71`, `Age19` |
| invalid type code → 0.0 | `categoryFromTypeCode` → optional | `InvalidTypeCodeReturnsZero` |

## 13. 회고 (9차)

### 13.1 달성

- README 4단계 5개 목표를 **FI ID·API·TC·실행 출력**까지 일관되게 매핑해 검증했다.
- 2차에서 구현된 SRP·FI 기능이 7~8차 TC 확장 이후에도 **회귀 없이 유지**됨을 확인했다.
- FI 핵심 4 TC에 GWT 주석을 추가해 **테스트 의도·요구사항 추적성**을 높였다.

### 13.2 설계 품질

- **파사드 + 단일 책임**: 기능 추가(FI) 시 `SHealth.cpp` 변경 없이 `BmiStatistics`/`DataImputer`만 확장.
- **보정 순서 고정**: weight → height → BMI로 결측 의존성 명확.
- **레거시 호환**: `getBmiRatio`·`computeBmi` 유지로 기존 호출부·TC 안정.

### 13.3 한계

- README 본문은 체중 0 보정만 명시 — 키 보정·FI API는 **기능 개선·요구사항 분석 문서**에 의존.
- `shealth.dat` 통합 TC 미포함 — 수치 회귀는 수동 실행으로만 확인.
- GWT 주석은 FI 핵심 4 TC에만 보강 — 나머지 32 TC는 7차 형식 유지.

## 14. 부록 — 파사드 코드

```cpp
int SHealth::processFile(const std::string& filename) {
    records_.clear();
    if (!csvReader_.load(filename, records_)) {
        return -1;
    }
    DataImputer::imputeMissingValues(records_);
    BmiCalculator::applyToAll(records_);
    statistics_.compute(records_);
    return static_cast<int>(records_.size());
}
```
