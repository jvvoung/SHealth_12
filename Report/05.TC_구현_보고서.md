## 4. 테스트 구조

### 4.1 Fixture 계층

```
::testing::Test
├── CsvProcessFixture          … 고유 CSV 경로, writeCsv, processBody, TearDown 삭제
│   ├── CsvReaderTest          (4건)
│   └── SHealthProcessTest     (5건)
├── RecordsPipelineFixture     … records_ + runPipeline()
│   ├── DataImputerTest        (4건)
│   └── BmiStatisticsTest      (8건)
└── BmiCalculatorTest          (5건, 베이스 없음)

기존: TEST(SHealthBmiTest, …) × 10  … writeTempCsv (고정명, 하위 호환)
```

**설계 원칙**

- Fixture 간 **mutable 공유 상태 없음** (테스트별 `records_` / `path_` 인스턴스)
- `CsvProcessFixture`: `test_shealth_{counter}.csv` 로 병렬·재실행 충돌 완화
- 기존 10건은 `test_shealth_temp.csv` 고정명 유지 (회귀 호환)

### 4.2 모듈별 신규 TC (26건)

| Fixture | 건수 | 검증 API·시나리오 |
|---------|------|-------------------|
| **BmiCalculatorTest** | 5 | `classify(22.99/24.99)`, `compute` 음수 height, `applyToAll`, bmi=0 분류 |
| **DataImputerTest** | 4 | 전원 weight=0, w·h 동시 0, validCount=0, height 보정 |
| **CsvReaderTest** | 4 | 파일 없음, 헤더만, 3열 skip, 빈 줄·bad-row |
| **BmiStatisticsTest** | 8 | bmi≤0 제외, age 19/20/29/71/80, Normal ID 0·복수, 빈 연령대, 단일 overall 100% |
| **SHealthProcessTest** | 5 | `processFile(-1)`, 헤더만, typeCode 100~400, `getBmiRatio` 일치, 연령 통합 |

### 4.3 Assertion 규칙 (적용 내역)

| 용도 | 매크로 | 허용 오차 |
|------|--------|-----------|
| BMI 값 | `EXPECT_NEAR` | **0.01** |
| 보정 후 BMI 일치 | `EXPECT_NEAR` | **0.001** |
| 비율(%) | `EXPECT_NEAR` | **0.01** |
| `BmiCategory`·건수·ID | `EXPECT_EQ` / `ASSERT_EQ` | — |
| bmi=0, invalid height | `EXPECT_DOUBLE_EQ` | — |
| `categoryFromTypeCode` | `EXPECT_TRUE/FALSE(has_value())` | — |

각 `TEST_F` 상단에 **Given / When / Then** 3줄 주석을 두었습니다.

## 9. 구현 시 유의·결정 사항

### 9.1 TC-22 단일 레코드 데이터

- 초기 입력 `50kg / 160cm` → BMI ≈ 19.53 (**Normal**)으로, Underweight 100% assert 실패.
- **수정:** `45kg / 170cm` → Underweight, overall 합 100% 검증 성공.

### 9.2 빈 연령대 `getDecadeDistribution`

- 유효 decade 인덱스이나 데이터 없을 때: **빈 배열이 아니라 0으로 채운 `CategoryRatios`** 반환.
- assert는 `empty()` 대신 **모든 비율 0.0** 으로 검증.

### 9.3 MSVC C4819

- 한글 Given-When-Then 주석으로 인해 코드 페이지 경고 가능.
- 기능에는 영향 없음; 필요 시 파일 UTF-8 BOM 저장 또는 주석 영문화로 완화.
