    - 도메인:
      · BMI = weight(kg) / (height(m))²
      · 분류: ≤18.5 저체중, 18.5<~23 정상, 23≤~25 과체중, ≥25 비만 (25.0 포함)
      · weight=0 → 동 연령대(10년 단위) 평균 체중 대체 (README 기존)
      · 연령대: 20~70세, 10년 단위
    - 레거시 API(getBmiRatio, computeBmi 등) 하위 호환 유지

[T] README 4단계(155~158행) 기능 4개를 구현해줘.

    ## 공통 선행: SRP 책임 분리 (154행)
    - God Class(SHealth)에서 I/O·파싱·보정·계산·통계를 분리
    - 권장 클래스: CsvReader, BmiCalculator, DataImputer, BmiStatistics, SHealth(파사드)
    - processFile은 위 컴포넌트를 순서대로 조율만

    ## FI-01: 특정 연령대 BMI 분포 비율 (155행)
    - 입력: ageDecade (20, 30, …, 70)
    - 출력: 해당 연령대 4분류(저체중/정상/과체중/비만) 비율(%)
    - API 예: getDecadeDistribution(int ageDecade) → CategoryRatios
              getCategoryRatio(int ageDecade, BmiCategory)와 값 일치
    - invalid decade / 해당 대 유효 인원 0 → 0% 반환, 크래시 금지

    ## FI-02: Height=0 평균치 보정 (156행)
    - weight=0과 동일 패턴: heightCm==0 → 동 연령대 평균 height로 대체
    - 보정 순서: weight 보정 후 height 보정 (또는 일관된 단일 순서 문서화)
    - 동 대 validCount=0 → 미보정 유지
    - 보정 후 BmiCalculator로 BMI 재계산

    ## FI-03: 정상 BMI 사용자 ID 목록 (157행)
    - 조건: 18.5 < BMI < 23 이고 bmi > 0 (무효 BMI 제외)
    - API 예: getNormalBmiUserIds() → vector<int> (처리 순서 유지)
    - 0건이면 빈 vector

    ## FI-04: 전체 사용자 BMI 범주별 비율 (158행)
    - 대상: 연령대 무관, 유효 BMI(bmi>0) 전체
    - API 예: getOverallDistribution() → CategoryRatios (4합 ≈ 100%)
              getOverallCategoryRatio(BmiCategory) → 단일 범주 %
    - 유효 BMI 0명 → 0% 반환

    ## 구현·검증 요구
    - SHealthBMI.cpp: 전체 분포·정상 BMI 사용자 출력 추가 (기존 연령대 출력 유지)
    - CMakeLists.txt: 신규 .cpp/h를 shealth_lib에 등록
    - Google Test 추가 (Given-When-Then 주석):
      · ImputeMissingHeightByDecade
      · DecadeDistributionMatchesCategoryRatio
      · OverallCategoryRatio
      · NormalBmiUserIds
    - 기존 TC 회귀 없이 ctest Green
    - 이미 구현되어 있으면: 갭 분석 → 미구현·미테스트 부분만 보강

    ## 변경 금지
    - HealthRecord 필드 의미 변경
    - getBmiRatio / LegacyTypeCode 하위 호환 깨뜨리지 않기
    - BMI 분류 경계(18.5, 23, 25) 임의 변경

[F] 구현 완료 후 요약:
    - 추가·변경 파일 목록

    - 빌드·실행·ctest 명령 및 결과
